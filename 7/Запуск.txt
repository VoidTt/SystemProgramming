Откройте 7.11.sln в Visual Studio 2022 с компонентами .NET Desktop Development.
Правой кнопкой по нужному проекту → Назначить запускаемым проектом → F5.

1 — ввод своих данных и несколько окон MessageBox через Windows API.
2 — сначала запустите Task2_Target (Ctrl+F5), затем Task2_Controller.
    По умолчанию ищется окно «Мое окно». После переименования вводите новый заголовок.
3 — звуковые сигналы Beep и MessageBeep; громкость зависит от настроек Windows.
4 — сначала Task4_Target, затем Task4_Controller. Контроллер делает поле только для чтения и отключает кнопку.
Все окна для экспериментов принадлежат этим примерам.
